Acces reserve. L'APK vit dans le depot prive : GitHub ne la sert qu'a un navigateur connecte au compte. Un robot qui passe par ici recoit une page introuvable. Si le lien renvoie une erreur 404, c'est que la session a expire : se connecter a GitHub, puis revenir ici.

Installation

  1. Touche le bouton ci-dessus, puis Telecharger quand meme si Chrome previent.
  2. Ouvre le fichier depuis la notification ou Fichiers > Telechargements.
  3. Android demande d'autoriser cette source : Parametres, puis Autoriser, puis reviens en arriere.
  4. Installer. Les builds suivantes se posent par-dessus sans desinstaller, la sauvegarde est conservee.
