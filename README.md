# OilMVP - builds de playtest

Depot de DISTRIBUTION uniquement. Le code source d'OilMVP est ailleurs et reste prive.
Ici il n'y a que des APK de playtest et la page qui permet de les telecharger depuis un
telephone, n'importe ou, sans compte et sans cable.

## Telecharger

Page : https://polspock.github.io/OilMVP-builds/

Lien direct, toujours la derniere build :
https://github.com/PolSpock/OilMVP-builds/releases/latest/download/OilMVP.apk

## Ce qui publie ici

Le workflow `APK` du depot source construit l'APK puis cree une release ici.
Rien ne se pousse a la main dans ce depot, sauf la page `index.html`.

## Signature

Toutes les builds sont signees avec la meme cle. Une nouvelle build s'installe donc
par-dessus la precedente, sans desinstallation et sans perte de sauvegarde.
